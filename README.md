# QGroundControl - URDL Fork

This repository is a fork of the [QGroundControl](https://github.com/mavlink/qgroundcontrol) project. It has been customized by **URDL - UAV Research and Development Laboratory** to tailor the application for our specific requirements.

## Purpose

- Adapt QGroundControl for URDL's UAV research and development needs.
- Integrate features and modifications unique to URDL workflows.
